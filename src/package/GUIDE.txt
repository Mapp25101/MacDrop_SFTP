SFTP DRIVE – an SFTP / FTP / FTPS server as a folder in Finder
===============================================================

INSTALL
-------
1. Unzip the download and double-click "SFTP Drive".
2. If macOS says the app cannot be opened (unidentified developer):
   System Settings → Privacy & Security → scroll down → "Open Anyway".
3. The app offers to move itself to Applications – confirm.
4. On first launch it installs the helper tool rclone and opens the
   "Add server" window: protocol (SFTP / FTP / FTPS), address, port,
   user name, password (stored in the Keychain), a folder name
   (e.g. "School") and the mode – Online or Synced copy (see below).
5. Done – a cloud icon appears in the menu bar and everything starts
   automatically from now on.

The "SFTP Drive" folder is added to the Finder sidebar automatically.

Update: unzip the new version and open it – it replaces the old one.
Apple-silicon Macs only (M1 and newer), macOS 13 or newer.


TWO MODES
---------
Inside the "SFTP Drive" folder every server gets its own folder (e.g.
"School"). Each server uses one of two modes:

ONLINE (like WinSCP) – the folder is the server itself. You see everything,
files open straight from the server, edits and dragged-in files are uploaded
right away. Nothing is stored on this Mac (edited files are kept briefly in
memory only). Without internet the folder is unavailable – it disconnects
cleanly and comes back by itself when the server is reachable again.

SYNCED COPY (like Google Drive) – the files live on your disk, so they work
offline, and they are synchronised both ways:
  • whatever you copy into the folder or edit is uploaded to the server,
  • whatever changes on the server is downloaded automatically,
  • whatever you delete in the folder is deleted on the server too.
If a file changes on both sides at once nothing is lost – the older version
is kept next to it as "file.conflict1.txt".

Choose which folders are downloaded in the menu-bar menu →
"Choose synchronised folders…" (or right-click in Finder). Whatever you
uncheck is removed from the Mac only – it stays on the server.


WHEN THE INTERNET DROPS
-----------------------
Online mode: the folder disconnects (read-only and empty) until the server is
reachable again – no frozen Finder, no "connection interrupted" dialogs.
Synced copy: keep working as usual. Files that are not on the server yet carry an orange
Finder tag "Waiting to upload". As soon as the connection is back they
upload by themselves within seconds and the tag disappears. No warnings and
no "eject disk" dialogs.


AFTER STARTING THE MAC
----------------------
Everything starts by itself (the app and the synchronisation). If the Mac
boots without internet, the sync waits and catches up as soon as the
connection appears. If anything fails to start, the app repairs it within
seconds. If macOS shows "Background item added" during the installation,
leave it enabled.


MENU-BAR ICON
-------------
✓ everything synced · ↻ syncing · ⚠ error · crossed-out = no connection
The menu: open the folder, sync now, choose folders, rename the folder,
pause, change the password, show the log, add another server, uninstall.
If your menu bar is full macOS may hide the icon – click » in the bar.


UNINSTALL
---------
Menu-bar icon → "Uninstall SFTP Drive…" (the app moves itself to the Trash),
or double-click "Uninstall.command" from the ZIP – it removes everything.
Data on the servers is never touched.
